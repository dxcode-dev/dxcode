# Contributing

Open an issue before undertaking a large change. Keep pull requests focused and
include tests for changed behavior. Run the same format, lint, typecheck, test,
and build commands as `.github/workflows/ci.yml` before submitting.

Contributions use the Developer Certificate of Origin. Sign every commit with
`git commit -s` to certify that you have the right to submit the work under the
repository license. See https://developercertificate.org/.

The public repository is a release projection. Maintainers manually port
accepted public changes to the private development repository. A later release
will contain the ported change; public commits are not merged into private
history verbatim.
