## What you get

<CardGrid>
  <Card title="A computer per Thread" icon="laptop">
    Every [Thread](/docs/use/getting-started/#start-a-thread) runs in its own
    Orb: a Linux sandbox with the project's repository cloned in, a Terminal you share
    with the agent, and a Desktop with Chromium.
  </Card>
  <Card title="Your models" icon="puzzle">
    Run Claude Code on your Claude Pro or Max plan, serve models from GitHub
    Copilot, add a provider's API key, or point at any OpenAI- or
    Anthropic-compatible endpoint.
  </Card>
  <Card title="Your Orb providers" icon="setting">
    Orbs run on a provider your deployment offers, or in your own E2B,
    Cloudflare, Freestyle, Docker, or Boat account, on your plan and bill.
  </Card>
  <Card title="Agents that start agents" icon="rocket">
    An agent can start child Threads that work in parallel in their own Orbs,
    then report back to the Thread that started them.
  </Card>
</CardGrid>

## Quickstart

<Steps>

1. **Sign in.** Open dx and sign in with an email link, a password, or
   Google, whichever your deployment offers.

2. **Connect a model.** In **Personal Settings → Model Routing**, choose
   **Add**. See [Connecting a model](/docs/use/connect-a-model/).

3. **Connect an Orb provider.** Open **Personal Settings → Orb Providers**.
   If a provider reads **Provided by this deployment**, skip this step;
   otherwise choose **Connect** next to one. See
   [Connecting an Orb provider](/docs/use/connect-an-orb-provider/).

4. **Start a Thread.** Create a project from a repository, choose
   **New Thread**, and describe a task you can check. See
   [Getting started](/docs/use/getting-started/).

</Steps>
