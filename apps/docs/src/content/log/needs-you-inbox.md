## Needs you

A **Needs you** button now sits at the top of the sidebar, beside **Mentions**. It lists your Threads that wait on you, across projects, newest first:

- a question from the agent,
- a request for your approval,
- a root Thread whose turn failed.

A Thread leaves the list when its next turn starts, or when you choose **Dismiss**.

## Threads linked to issues

A Thread can now link to the GitHub issues and pull requests it works on. The agent links them as it goes, and a Thread that follows an issue's or pull request's comments links to it too. The Thread's header shows its linked issues, and its pull requests join the header's pull request list.

To find the Thread for an issue, search for `issue:owner/repo#12` in Thread search, or for `issue:` followed by the issue's GitHub URL.
