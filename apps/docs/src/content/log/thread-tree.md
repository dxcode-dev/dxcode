Agents that start agents can build deep families of Threads. Two changes make them easier to follow.

## A tidier sidebar

Under a root Thread, the sidebar now lists only the Threads the root started itself. A child that started Threads of its own shows a count of the Threads below it. Select the count to open the Thread tree.

## The Thread tree page

Open any Thread and choose **More Actions → Open Thread Tree**. The page shows the whole family as an outline: each Thread sits under the one that started it, and the Thread you came from is marked. Collapse a branch to focus on the rest, and use the back arrow to return to the Thread.

The tree lists active Threads. Archived children drop out, and their active children move up under the root. An archived root stays at the top, dimmed.
