---
title: Limit an MCP server to chosen projects
date: 2026-10-31
summary: Choose which projects' Threads can use each MCP server, from the server's settings.
kind: news
---

An MCP server no longer has to reach every Thread you start.

In **Settings → Integrations & MCP**, choose **Configure** on a server and find **Projects**:

- **All projects**: every project's Threads, including new projects.
- **Only these**: only Threads in the projects you pick.

A Thread in a project you left out does not get the server. A personal server can be limited to your projects and your workspace's; a workspace server, to the workspace's projects.
