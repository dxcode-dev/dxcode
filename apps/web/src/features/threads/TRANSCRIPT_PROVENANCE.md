# Transcript implementation provenance gate

The transcript view-model is original dx code derived only from Flue's public native
types. External projects are design evidence, not copied runtime dependencies.

- Vercel AI Elements is Apache-2.0. Any later source intake must retain its required
  notice and receive a component-level provenance review.
- TanStack Virtual and TanStack Pacer are MIT. Pacer is already present; this issue
  adds neither Virtual nor another dependency.
- The paid `@virtuoso.dev/message-list` (Virtuoso Message List) was not approved for
  this implementation. Do not copy or install it under an open-source assumption.
  The separate React Virtuoso core project is MIT, but is not used here.

T3 Code and OpenAI Codex informed behavioral invariants only. No source from those
projects was adapted for this implementation.
